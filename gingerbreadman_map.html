Guide: A Chaotic Cookie

The Gingerbreadman map is another famous example of a simple set of mathematical rules that produces intricate, chaotic behavior. Like the Hénon map, its long-term behavior is governed by a strange attractor—a set of points towards which the system evolves, and which has a fractal structure.

The map gets its name simply because the shape of the attractor resembles a gingerbread man. When you click on the canvas, you provide an initial point `(x₀, y₀)`. The simulation then iterates the map's equations thousands of times. You will see that regardless of where you click, the points quickly converge onto the same iconic shape. The trajectory then wanders around this attractor forever, never repeating and never settling down, but always staying confined to the attractor's structure.

The key to the map's chaotic behavior is the absolute value term, `|xₙ|`, which provides a "folding" action similar to the quadratic term in other chaotic maps.

The Gingerbreadman Map Equations

The map iterates a point `(x_n, y_n)` to the next point `(x_{n+1}, y_{n+1})` according to the following equations:

x_{n+1} = 1 - y_n + |x_n|
y_{n+1} = x_n
