Radioactive Half-Life Dice Game

An analogy for the probabilistic nature of radioactive decay.

Plain-Language Overview

Radioactive decay, where an unstable atomic nucleus breaks down, is a fundamentally random process. We can never know exactly when one specific nucleus will decay. However, for a large collection of nuclei, their collective behavior is very predictable. This simulation uses a large number of dice as an analogy for radioactive nuclei. Each "roll" is a unit of time, and if a die lands on a chosen "decay number," it's considered decayed. This simple game beautifully demonstrates the concepts of probability, exponential decay, and half-life.

Beginner's Guide — The Dice Analogy

Step 1: The Setup

Imagine each die in the simulation is a single, unstable atomic nucleus. We start with a large number of these "undecayed" dice. Each roll of all the dice represents one unit of time passing (e.g., a year, a minute, a second).

Step 2: The Decay Rule

We need a rule for when a die "decays." In this simulation, you can select one or more numbers on the die face (from 1 to 6) to be the "decay numbers." For example, if you select only the number "1," then any die that lands on a 1 after a roll is considered "decayed." The probability of any single die decaying in one roll is 1/6. If you select "1" and "2," the probability becomes 2/6, or 1/3.

Step 3: Randomness and Predictability

This is the core concept. For any single die, you can't predict if it will decay on the next roll. It's completely random. However, for a large number of dice, you can be very confident that *about* 1/6th of them will decay on each roll (if "1" is the decay number). This is exactly how radioactive decay works: the process is individually random but collectively predictable.

Step 4: Exponential Decay and Half-Life

As you repeatedly click "Roll All Dice," you'll see the number of active (undecayed) dice decrease. The graph below the dice grid plots this decrease. You'll notice it's not a straight line; it's an **exponential decay curve**. The number of decays is large at the beginning when there are many dice, and it gets smaller as the number of remaining dice dwindles.

The **half-life (`T₁/₂`)** is a crucial concept. It's the time required for exactly half of the initial nuclei to decay. In our game, it's the number of rolls it takes for the number of active dice to drop to half its starting value. The simulation will mark this point on the graph for you.

The Law of Radioactive Decay

The number of undecayed nuclei, `N(t)`, remaining at time `t` follows an exponential decay law:

N(t) = N₀ * e^(-λt)

Where `N₀` is the initial number of nuclei, `e` is the base of the natural logarithm, and `λ` (lambda) is the **decay constant**. The decay constant represents the probability per unit time that a single nucleus will decay. In our dice analogy, `λ` is directly related to the probability `p` of rolling a decay number on a single roll (`p = number of decay faces / 6`). For a discrete process like ours, the equation is `N(t) = N₀ * (1-p)ᵗ`.

Half-Life (`T₁/₂`)

The half-life is the time it takes for `N(t)` to become `N₀/2`. We can solve for it by setting `N(t) = N₀/2` in the decay equation:

N₀ / 2 = N₀ * e^(-λ * T₁/₂)

1/2 = e^(-λ * T₁/₂)

Taking the natural logarithm of both sides gives `ln(1/2) = -λ * T₁/₂`, which simplifies to `-ln(2) = -λ * T₁/₂`. Therefore, the relationship is:

T₁/₂ = ln(2) / λ ≈ 0.693 / λ

This shows that a larger decay constant (a higher probability of decay) leads to a shorter half-life.
