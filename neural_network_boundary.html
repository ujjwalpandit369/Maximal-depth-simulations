Plain-Language Overview

A neural network, at its core, is a powerful pattern-recognition machine. When we "train" a network to classify data—for example, to tell cats from dogs—we are asking it to learn a "decision boundary." Think of this as drawing a line or a curve on a map to separate the cat pictures from the dog pictures. This simulation lets you see that process live. You can place blue and pink dots on the 2D map, and then tell the neural network to "Train." You will see the network's decision boundary—the line where its prediction flips from blue to pink—shift and curve as it adjusts its internal "weights" to best separate your data points.

Beginner's Guide

1. What is a Decision Boundary?

The colored background on the canvas represents the neural network's current prediction for every single point in the space. The line where the color changes from pink to blue is the decision boundary. Everything on one side, it classifies as "blue"; everything on the other, it classifies as "pink." The goal of training is to move this boundary so that all the actual blue dots are in the blue region and all the pink dots are in the pink region.

2. How Does a Neural Network "Learn"?

A neural network is made of simple processing units called "neurons," organized in layers. Each connection between neurons has a "weight," which is just a number. These weights determine the strength of the connections.

  • Forward Pass: When we give the network an input (the (x,y) coordinates of a dot), the information flows through the network. Each neuron takes a weighted sum of its inputs and applies a simple non-linear function (an "activation function") to produce its output. This process continues until the final layer produces a prediction.
  • Calculating Loss: The network compares its prediction to the actual label of the data point. The "loss" or "error" is a measure of how wrong the prediction was.
  • Backpropagation: This is the magic of learning. The network calculates how much each individual weight contributed to the total error. It then "propagates" this error information backward through the network.
  • Weight Update: Each weight is nudged slightly in the direction that would have made the error smaller. The size of this nudge is controlled by a parameter called the "learning rate."
By repeating this process thousands of times with all the data points, the network's weights are gradually adjusted, causing the decision boundary to shift and curve to better fit the data.

3. Exploring the Simulation

Try the different presets to see how the network performs on different problems:

  • Linear: This is an easy problem. The network should quickly learn a straight line to separate the two clusters.
  • Circle: This problem is impossible to solve with a single straight line. The network needs to use its "hidden layers" to learn a more complex, circular boundary.
  • Spiral: This is a very difficult problem that tests the network's ability to learn highly complex, non-linear functions. Watch how the boundary has to twist and turn to separate the two intertwined arms of the spiral.

You can also add your own points to see how the network adapts to new information during training.

Core Theory in a Nutshell

Forward Propagation

For a single neuron, the output a is calculated from its inputs xi and weights wi, plus a bias b.

z = (Σ wixi) + b
a = σ(z)

Where σ is a non-linear activation function, like the Sigmoid function: σ(z) = 1 / (1 + e-z). This squashes the output to be between 0 and 1. This process is repeated for each layer, with the outputs of one layer becoming the inputs for the next.

Backpropagation (Weight Update)

The network's error is measured by a loss function, for example, Mean Squared Error: Loss = ½ (ytrue - ypred)2. Backpropagation uses the chain rule from calculus to find the gradient of the loss with respect to each weight (∂Loss/∂w). The weight is then updated:

wnew = wold - η × (∂Loss/∂wold)

Where η (eta) is the learning rate, a small number that controls how big of a step to take. This simple update rule, applied iteratively, is what drives the learning process.
