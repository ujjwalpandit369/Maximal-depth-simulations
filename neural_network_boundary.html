Plain-Language Overview

A neural network is a powerful pattern-recognition machine. When we "train" it to classify data—for example, to tell cats from dogs—we are asking it to learn a "decision boundary." Think of this as drawing a line or a complex curve on a map to separate the cat pictures from the dog pictures. This simulation lets you see that process live. You can place data points (pink and blue dots) on the 2D map, design a neural network by choosing its layers and other properties, and then tell it to "Train." You will see the network's decision boundary—the background color where its prediction flips from pink to blue—shift and curve as it adjusts its internal connections ("weights") to best separate your data points.

Beginner's Guide

1. What is a Decision Boundary?

The colored background on the canvas represents the neural network's current prediction for every single point in the space. The line where the color changes from pink to blue is the decision boundary. Everything on one side, it classifies as "blue"; everything on the other, it classifies as "pink." The goal of training is to move this boundary so that all the actual blue dots are in the blue region and all the pink dots are in the pink region.

2. How a Neural Network "Learns"

A neural network is made of simple processing units called "neurons," organized in layers. Each connection between neurons has a "weight," which is just a number that can be tuned.

  1. Forward Pass: When we give the network an input (the (x,y) coordinates of a dot), the information flows through the network. Each neuron takes a weighted sum of its inputs and applies a non-linear "activation function" to produce its output. This continues until the final layer produces a prediction.
  2. Calculating Loss: The network compares its prediction to the actual label of the data point. The "loss" or "error" is a measure of how wrong the prediction was. A high loss means it was very wrong.
  3. Backpropagation: This is the magic of learning. The network uses calculus (specifically, the chain rule) to calculate how much each individual weight contributed to the total error. It "propagates" this error information backward through the network.
  4. Weight Update: Each weight is nudged slightly in the direction that would have made the error smaller. The size of this nudge is controlled by the Learning Rate (η).
By repeating this process thousands of times (in "epochs"), the network's weights are gradually adjusted, causing the decision boundary to shift and curve to better fit the data.

3. Exploring the Simulation

Use the controls to see how different parameters affect learning.

  • Data Presets: Try the different presets to see how the network handles different problems. The "Linear" data is easy. The "Circle" data requires a non-linear boundary. The "Spiral" data is very difficult and requires a complex network (try more layers/neurons).
  • Learning Rate: Try training on the Circle data with a very high learning rate (e.g., 1.0). The boundary will likely jump around erratically and fail to settle. Now try a very low rate (e.g., 0.001). It will learn, but very slowly. This shows the trade-off.
  • Network Architecture: Try solving the Spiral data with just 1 hidden layer and 4 neurons. It will likely fail. Now increase the layers to 3 and neurons to 12. Reset the weights and train again. It should now have enough "capacity" to learn the complex shape.

Worked Walkthroughs & Micro-Experiments

Walkthrough: The Effect of Network Depth

  1. Click "Spiral Data" to load the difficult dataset.
  2. In the controls, set Hidden Layers to 1 and Neurons/Layer to 4. Click "Reset Weights", then "Train". Observe that the network tries, but can only form a simple curve and the loss value stays high. It is underfitting.
  3. Pause training. Now, set Hidden Layers to 3 and Neurons/Layer to 12. Click "Reset Weights" and "Train" again.
  4. Notice how the decision boundary can now twist and turn to follow the spiral arms. The final loss will be much lower. This demonstrates that a deeper, wider network has more capacity to learn complex functions.

Micro-Experiments

  1. Load "Circle Data". Set learning rate to 1.0. Train. What happens? (The loss jumps around violently, a sign of unstable training).
  2. Reset. Set learning rate to 0.01. Train. What happens? (It learns, but very slowly). Find the "Goldilocks" rate in between.
  3. Load "Linear Data". Set layers to 4 and neurons to 16 (a very powerful network). Train. Notice that the boundary might become overly "wiggly" around the data points. This is overfitting: the network is too powerful for the simple data.
  4. Select "ReLU" as the activation function. Notice that the decision boundaries are made of sharp, straight lines. Why? (ReLU is a piecewise linear function).
  5. Select "Tanh" or "Sigmoid". Notice the boundaries are smooth and curved.
  6. Clear all data. Place one pink dot in the top left and one blue dot in the bottom right. Train a simple network. It will create a simple line between them. Now add a blue dot in the top left. The boundary will curve to accommodate it.

Core Theory in a Nutshell

For a single neuron, the output a is calculated from its inputs xi and weights wi, plus a bias b.
z = (Σ wixi) + b
a = f_act(z)
Where f_act is a non-linear activation function like Tanh or ReLU. This process is repeated for each layer. The network's error is measured by a loss function, like Mean Squared Error: Loss = ½ (y_true - y_pred)2. Backpropagation uses the chain rule from calculus to find the gradient of the loss with respect to each weight (∂Loss/∂w). The weight is then updated:
w_new = w_old - η × (∂Loss/∂w_old)
Where η is the learning rate. This simple update rule, applied iteratively, drives all learning.

FAQ & Troubleshooting

1. What is an "epoch"?
An epoch represents one full pass of the training algorithm over the entire dataset. In this simulation, for performance, an epoch is simplified to a fixed number of training steps.
2. What is "loss"?
Loss is a number that measures how wrong the network's predictions are compared to the true labels. The goal of training is to minimize this number.
3. Why does the boundary stop changing even if the loss is not zero?
The training may have gotten stuck in a "local minimum," a point where any small change to the weights increases the loss. More advanced optimizers (like Adam or Momentum) help escape these.
4. Why is the training slow?
Training a neural network is computationally intensive! Even for this small 2D problem, thousands of calculations are happening per frame. For better performance, tick the "Performance Mode" box, which draws the background at a lower resolution.
5. What is the difference between activation functions?
They are different non-linearities. ReLU (Rectified Linear Unit) is simple and fast (output is max(0, z)). Tanh and Sigmoid are smooth, S-shaped curves. They have different mathematical properties that make them better for different kinds of problems.
