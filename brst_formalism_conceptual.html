The BRST Formalism (Conceptual)

A conceptual simulation of quantizing a gauge theory using cohomology.

Overview

In modern physics, gauge theories like electromagnetism have "unphysical" redundancies that must be removed to get sensible results. The BRST formalism is a powerful mathematical machine for doing this. It introduces unphysical "ghost" particles and a special "BRST operator" `Q` that acts on the entire space of states. The true physical states are then identified by a simple but profound rule known as cohomology. This simulation lets you build your own toy "theory" of states and `Q` operations and see how this rule automatically and correctly identifies the physical states within the larger, unphysical space you've created.

Beginner's Guide to Finding Physical States

This is a game about finding special states according to a set of rules. It mirrors a deep process in quantum field theory.

Step 1: The Space of States

The canvas represents a "space of states." Each dot is a state. In a real theory, this could be a photon, an electron, or an unphysical "ghost" particle. Here, they are just abstract points.

Step 2: The BRST Operator (Q)

The arrows represent the action of the "BRST Operator" `Q`. If an arrow goes from state A to state B, it means `Q|A⟩ = |B⟩`. `Q` has one crucial property: applying it twice gives zero (`Q²=0`). This means if an arrow goes from A to B, no arrow can ever start at B. The simulation enforces this rule for you.

Step 3: The Rules for Physicality (Cohomology)

A state is a true physical state if and only if it meets two conditions. The simulation checks these rules and colors the states accordingly:

  • Condition 1: The state must be "Closed." This means `Q|ψ⟩ = 0`. In our game, a state is closed if it has no arrows leaving it.
  • Condition 2: The state must NOT be "Exact." This means it cannot be the result of `Q` acting on something else. In our game, a state is exact if it has one or more arrows pointing to it.

The simulation uses the following color code:

  • Green (Physical): Closed but NOT Exact. (No arrows leaving, no arrows entering). These are the true physical states!
  • Purple (Exact, Not Closed): Not Closed and Exact. (Arrows leaving AND entering). Unphysical.
  • Yellow (Closed and Exact): Closed AND Exact. (No arrows leaving, but arrows entering). Unphysical.
  • Gray (Other): Not Closed and Not Exact. (Arrows leaving, but no arrows entering). Unphysical.

How to Use the Simulation

  1. Add States: Click on an empty part of the canvas to add a new state (a dot).
  2. Define Q: Click and drag from one state to another to create an arrow (define the action of Q). Remember, you can't create an arrow starting from a state that already has an arrow pointing to it.
  3. Observe the Colors: As you add states and arrows, watch how the colors of the states change instantly. Try to create a system with at least one green "physical" state.
  4. Right-Click: Right-click on a state or an arrow to remove it.

Controls

Click to add states. Drag between states to define the Q operator (arrows).
