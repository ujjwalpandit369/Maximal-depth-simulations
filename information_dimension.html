Chaos, Uncertainty, and Information

What is information? In a physical sense, information is the reduction of uncertainty. If a system is perfectly predictable, like a clock, observing it doesn't give you much new information after a while. But if a system is chaotic, it is fundamentally unpredictable. Each new observation gives you new information about its state. This simulation quantifies that idea using Shannon Entropy.

Step 1: The Chaotic System

The left panel shows the logistic map `x → 4x(1-x)`, a classic chaotic system. Its state `x` lives on the interval from 0 to 1. We have partitioned this state space into a number of discrete "bins," shown by the vertical gray lines. Instead of tracking the exact value of `x`, we will only record which bin it falls into at each iteration.

Step 2: Generating an Information Sequence

Click "Start". The simulation begins iterating the logistic map. The red line shows the "cobweb" plot of the iteration. At each step, the bin containing the current state is highlighted. The sequence of visited bins (e.g., "A, C, D, B, A...") is recorded.

Step 3: Measuring Information with Entropy

The right panel plots the Entropy Rate (H/n) of the sequence of visited bins. Shannon Entropy (H) measures the average uncertainty or "surprise" of the sequence. Dividing by the number of steps `n` gives the average information generated per iteration.

Watch the plot as the simulation runs:

  • Initially, the entropy rate fluctuates wildly because the sequence is short.
  • As the sequence gets longer and longer, the entropy rate will converge towards a stable, positive value.
This is the key result. A positive, constant entropy rate means the system is a persistent source of new information. No matter how long you observe it, the next step is still uncertain, and observing it resolves that uncertainty, giving you new information. This is a fundamental signature of chaos. For a predictable, periodic system, the entropy rate would eventually fall to zero.
