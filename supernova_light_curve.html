Welcome, Cosmic Detective!

How do we measure the vast distances to other galaxies? One of the most powerful tools is a special type of exploding star called a Type Ia Supernova. This simulation shows you how they work.

Step 1: The Light Curve

When a Type Ia supernova explodes, it gets incredibly bright and then fades over several weeks. The graph you see is its light curve, which plots its brightness over time.

  • The horizontal axis is Time in days.
  • The vertical axis is Apparent Magnitude. This is how bright the supernova appears from Earth. Warning: The magnitude scale is inverted—a smaller number means a brighter object!
The blue dots are the data points an astronomer might collect with a telescope.

Step 2: The "Standard Candle" Problem

At first, astronomers thought all Type Ia supernovae exploded with the exact same intrinsic brightness. They thought they were "standard candles"—if you know how bright something truly is, you can figure out how far away it is based on how dim it appears.

But they discovered this wasn't quite true. Some are intrinsically a bit brighter than others. Click the "Generate New Supernova Data" button a few times. You'll see different supernovae with different peak brightnesses. This was a problem!

Step 3: The Phillips Relation - A Cosmic Rosetta Stone

In the 1990s, astronomers led by Mark Phillips made a breakthrough discovery: the shape of the light curve is related to its true brightness.

  • Intrinsically brighter supernovae fade more slowly.
  • Intrinsically dimmer supernovae fade more quickly.
This is the key! We can use the shape to "standardize" the candle.

Step 4: Fit the Curve

Your job is to be the astronomer. Use the three sliders to fit the red model curve to the blue data points.

  1. Adjust Peak Time to line up the peak of the curve with the data's peak time.
  2. Adjust Peak Apparent Mag to match the height of the peak.
  3. Adjust the Stretch Factor (s). This is the crucial one. A value `s > 1` means the supernova fades slowly (a "stretched" curve). A value `s < 1` means it fades quickly. Adjust `s` to match the shape of the decline.
Try to get the "Goodness of Fit" number as low as possible.

Step 5: The Results

Once you have a good fit, look at the "Derived Properties" box. Based on the "Stretch Factor" you found, the simulation calculates the Inferred Absolute Magnitude (M)—the supernova's true brightness.

Now that it knows the true brightness (M) and the apparent brightness (m), it can calculate the Distance Modulus and the final Distance in Megaparsecs (Mpc). One Mpc is over 3 million light-years! You've just measured the distance to a galaxy millions of light-years away. This technique was used to discover that the expansion of the universe is accelerating, a discovery that won the Nobel Prize in Physics in 2011.

The Light Curve Model

A Type Ia supernova light curve is complex, but can be modeled by a template function that is adjusted by a "stretch" parameter, `s`. A simplified model for the magnitude `m(t)` at time `t` after peak can be written based on a template magnitude `M_template`.

Equation: `m(t) = m_peak + M_template( (t - t_peak) / s )`

Where `s` is the stretch factor. If `s > 1`, time is effectively slowed down, making the decline slower. If `s < 1`, the decline is faster.

The Phillips Relation

This is an empirical relationship that connects the stretch factor `s` (or a similar shape parameter like Δm₁₅, the decline in magnitude 15 days after peak) to the absolute magnitude `M` at peak brightness.

Equation: `M_peak = M_ref + α · (s - 1)`

Where `M_ref` is the absolute magnitude for a standard supernova with `s=1` (typically around -19.3), and `α` is a correlation coefficient (the "alpha" parameter, typically negative).

Plain English: Start with a reference brightness. If the supernova is stretched (s > 1), it's intrinsically brighter, so we adjust M downwards (brighter). If it's fast-declining (s < 1), it's intrinsically dimmer, so we adjust M upwards (dimmer).

The Distance Modulus

This is the fundamental equation connecting apparent magnitude (m), absolute magnitude (M), and distance (d) in parsecs.

Equation: `μ = m - M = 5 · log₁₀(d) - 5`

By measuring `m` (from the light curve peak) and inferring `M` (using the Phillips relation), we can solve for `d`.

Solved for distance: `d = 10 ^ ((m - M + 5) / 5)` parsecs.
