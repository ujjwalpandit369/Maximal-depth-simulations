The Causal Dynamical Triangulation (CDT) Universe

Building spacetime from the ground up, one triangle at a time.

Plain-Language Overview

How do you build a universe? Causal Dynamical Triangulations (CDT) is a fascinating approach to quantum gravity that tries to answer this question literally. It assumes that spacetime, at the tiniest level, is not smooth but is built from tiny, identical, geometric building blocks (like triangles). The simulation starts with a random soup of these blocks and then, following a simple set of rules—most importantly, a rule that enforces cause-and-effect—it lets them rearrange themselves. Over millions of random "moves," a stable, large-scale universe with familiar properties like 4 dimensions and a recognizable expansion history "emerges" from the chaos. This simulation lets you watch a simplified 2D version of this process, seeing a universe assemble itself from first principles.

Note on Simplification: This simulation shows CDT in 2 dimensions (1 space + 1 time) because it is possible to visualize. The actual research is done in 4 dimensions, but the core principles of using building blocks, causality, and a Monte Carlo method are the same.

Beginner's Guide — A Gentle Introduction

Step 1: The Problem of Quantum Gravity

Modern physics has two incredibly successful theories: General Relativity (describing the large-scale universe of gravity, planets, and galaxies) and Quantum Mechanics (describing the small-scale universe of particles and forces). The problem is, they don't play well together. When we try to describe situations where both are important, like the center of a black hole or the Big Bang, the math breaks down. "Quantum Gravity" is the name for the search for a single theory that can unite them.

Step 2: Building Spacetime from LEGOs

Most approaches to physics assume spacetime is a smooth, continuous fabric. CDT takes a different approach, called "non-perturbative." It assumes spacetime is fundamentally discrete, like a digital image is made of pixels. The building blocks in CDT are called "simplices"—in 2D, these are simple triangles. The idea is to glue these triangles together to form the fabric of spacetime.

Analogy: Building with LEGOs. Imagine trying to build a smooth sphere out of tiny LEGO bricks. You can't make it perfectly smooth, but if the bricks are small enough, you can get a very good approximation. CDT proposes that the universe is like this LEGO sphere, and the simplices are the fundamental bricks.

Step 3: The Secret Ingredient: Causality

Early attempts at this, called "Dynamical Triangulations," failed spectacularly. When the triangles were allowed to connect in any way they wanted, they created bizarre universes. Most outcomes were either crumpled, point-like universes with an infinite number of dimensions, or thin, polymer-like chains with only one dimension. Nothing looked like our world.

The breakthrough of CDT was adding one simple, crucial rule: causality. This means that triangles must be glued together in a way that respects a clear distinction between space and time. We create discrete time "slices" and only allow triangles to connect adjacent slices. This forbids the universe from folding back on itself in time. It's like a rule for our LEGO model that says: "You must complete each horizontal layer before you can start building the next one up."

Step 4: Let the Universe Cook (The Monte Carlo Method)

How do we find the "correct" way to glue the triangles? We don't. We let the simulation find it for us using a "Monte Carlo" method.

  1. Start with a simple, random arrangement of triangles (e.g., a small stack of rings).
  2. Repeatedly try to make a small, random change (e.g., "flipping" an edge between two triangles).
  3. Use a set of rules (the "Einstein-Hilbert action" in physics terms) to decide if the change was "good" or "bad." A good change makes the geometry smoother and more stable.
  4. If the change is good, keep it. If it's bad, usually reject it, but sometimes accept it anyway. This small chance of accepting a bad move is crucial to prevent the simulation from getting stuck in a rut.
After millions and millions of these tiny steps, the configuration of triangles settles into its most probable, most stable state. Amazingly, this final state looks like a real universe! The Regge Action and The Metropolis Algorithm

The decision to accept or reject a move is governed by physics, specifically a discrete version of the Einstein-Hilbert action that describes gravity in General Relativity. For our 2D simulation, this simplifies greatly. The "action," S, is a number that we want to minimize to find the most stable universe.

S = k₂ * N₂ - k₁ * N₁

Plain English: The action S is a weighted count of the number of triangles (N₂) and the number of vertices (N₁). The constants k₁ and k₂ are "coupling constants" that we can tune. In CDT, it turns out you don't need to tune these constants; the causal structure is the most important thing.

The simulation uses the Metropolis-Hastings algorithm:

  1. Propose a random move (e.g., flip an edge).
  2. Calculate the change in the number of triangles (ΔN₂) and vertices (ΔN₁). In the simplest 2D case with fixed N₂, we only care about the number of vertices. An edge flip changes the "order" (number of connected edges) of 4 vertices. The action is related to the sum of `(order_i - 6)²` for all vertices. A "smoother" universe has most vertices with order 6.
  3. Calculate the change in action, ΔS.
  4. If ΔS < 0, the new state is more "energetically favorable" (more stable), so we always accept the move.
  5. If ΔS > 0, the move is unfavorable. We might still accept it with a probability P = exp(-ΔS). This allows the system to explore more configurations and not get stuck.
This process, repeated millions of times, guarantees that the simulation will eventually find the most probable, stable configuration for the universe.
