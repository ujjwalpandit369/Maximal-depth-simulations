The Problem with Magnetic Monopoles

Imagine a magnetic "point charge"—a north pole without a south pole, called a monopole. Its magnetic field (B), shown as blue lines, would radiate outwards just like the electric field from an electron. This seems simple enough.

However, there's a huge mathematical problem. In physics, we like to describe magnetic fields using a more fundamental object called the vector potential (A), from which B can be derived. It turns out to be mathematically impossible to define a single, smooth vector potential `A` for the entire sphere around the monopole. Any attempt to do so creates a singularity—an infinitely long, thin line of undefinedness called a Dirac String.

Step 1: The Northern Chart

Physicists and mathematicians found a clever way around this. Instead of one description for the whole sphere, they use multiple overlapping "charts" or "patches."

Select the "Northern Chart (Aₙ)". This mathematical description works perfectly everywhere on the sphere... except for the South Pole. You can see the vector potential (A) as little teal arrows, and the unavoidable Dirac String singularity is shown as a red line going to the South Pole.

Step 2: The Southern Chart

Now, click the "Southern Chart (Aₛ)" button. We are now using a different mathematical formula for the vector potential. This one works perfectly everywhere... except for the North Pole! The Dirac string has now "jumped" to the top.

Step 3: The Fibre Bundle Solution

This is the beautiful solution. Neither `Aₙ` nor `Aₛ` is the "true" vector potential. Both are just valid "local" descriptions. The true physical object is the magnetic field `B` (the blue lines), which looks the same no matter which chart you use.

The modern description of this is a Fibre Bundle. Think of the sphere as the "base space." At every point on the sphere, there is an attached "fibre," which is an internal space of possible mathematical choices (in this case, the choice of phase, a U(1) symmetry). A "section" of this bundle is a choice of a point in each fibre—this corresponds to choosing a specific vector potential like `Aₙ`.

Because the bundle is "twisted," there is no single continuous section that covers the whole sphere. You must use at least two sections (our `Aₙ` and `Aₛ`). Where they overlap (the equator), they are related by a "transition function" or "gauge transformation." This structure perfectly describes the physics of a magnetic monopole without any true physical singularities, only artifacts of our chosen coordinate systems.
