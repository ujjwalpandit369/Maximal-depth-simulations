Poisson Manifolds: The Nambu Bracket

A simulation of dynamics using the Nambu bracket, via the Euler equations for a rigid body.

Overview

This simulation explores the fascinating motion of a spinning object, like a tumbling asteroid, through its "phase space." The state of the object is described by its angular momentum vector. Because the object conserves both its total angular momentum and its kinetic energy, its state is highly constrained. This simulation visualizes these constraints: the state must lie on the surface of a sphere (constant angular momentum) AND an ellipsoid (constant kinetic energy) simultaneously. The resulting trajectory is the curve formed by the intersection of these two shapes. This type of motion, governed by two or more conserved quantities, can be described by a mathematical object called a Nambu bracket, a generalization of the framework of classical mechanics.

Beginner's Guide to a Tumbling Asteroid

Let's look at the beautiful and complex motion of a spinning object.

Step 1: Phase Space

The 3D space you see is not physical space, but "phase space." Each point `(Lx, Ly, Lz)` represents the angular momentum of the object around its three principal axes. The moving white dot shows the current state of the spinning object.

Step 2: The Two Conserved Quantities

For a freely spinning object with no external forces, two key quantities are conserved (they never change):

  • H₁: Angular Momentum Squared. `L² = Lx² + Ly² + Lz²`. The set of all states with the same total angular momentum forms a sphere. This is shown as the blue wireframe sphere. The system's state must always be on the surface of this sphere.
  • H₂: Rotational Kinetic Energy. `E = Lx²/(2Ix) + Ly²/(2Iy) + Lz²/(2Iz)`. The set of all states with the same kinetic energy forms an ellipsoid. This is shown as the red wireframe ellipsoid. The system's state must also always be on this surface.

Step 3: The Trajectory - Where the Surfaces Meet

Since the system must obey both conservation laws at the same time, its state is forced to lie on the intersection of the sphere and the ellipsoid. The orange line shows this path. You can see the white dot, representing the system, moving perfectly along this curve. This path is called a "polhode," and it shows how the angular momentum vector changes relative to the body's own axes.

How to Use the Simulation

  1. Rotate the View: Click and drag on the canvas to rotate the 3D phase space and get a better view of the intersecting surfaces.
  2. Use the Sliders: The sliders control the moments of inertia (`Ix`, `Iy`, `Iz`), which describe how the mass is distributed in the object. Changing these values changes the shape of the red energy ellipsoid.
    • If all three moments are equal, the ellipsoid is a sphere, and the intersection is a single point—the object spins stably.
    • If they are different, the intersection becomes a complex curve.
  3. Reset: Click the "Reset" button to restart the animation with the new parameters.

Controls

Click and drag on the canvas to rotate the view. Use the sliders to change the object's properties and then press Reset.
