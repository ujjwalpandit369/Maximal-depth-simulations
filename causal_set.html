Guide: Spacetime as a Family Tree

Is Spacetime Smooth or Grainy?

General Relativity describes spacetime as a smooth, continuous fabric. Quantum mechanics suggests that at the smallest scales, everything is discrete, or "grainy." Causal Set Theory (or "Causets") is an approach to quantum gravity that takes discreteness as its starting point. It proposes that spacetime is not a continuous sheet, but a collection of fundamental, indivisible "atoms" of spacetime—the events you see in the simulation.

Causality is Everything

In this theory, the only fundamental structure is causality. Some events can influence others, and some cannot. This creates a "partial order" on the set of events.

  • An event `A` causally precedes an event `B` (`A ≺ B`) if `B` is in the future light cone of `A`.
  • The simulation shows these relationships by drawing lines between events. To keep the diagram clean, it only draws "links"—a connection from `A` to `B` is only drawn if there is no other event `C` in between them (`A ≺ C ≺ B`). This reveals the fundamental causal scaffolding of the spacetime.
Think of it like a family tree. The people are the discrete events, and the parent-child relationships are the causal links. You can't always say if one person is "before" another (e.g., two cousins), but the overall structure of the tree is defined by the causal relationships. Causal Set Theory proposes that everything we know about spacetime—its geometry, its dimension, even the laws of physics within it—is an emergent property of this simple, underlying causal network.
