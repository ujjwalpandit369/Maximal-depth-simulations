Overview

This simulation explores the intricate beauty of Julia sets, which are close cousins of the more famous Mandelbrot set. Both fractals are generated by the simple iterative equation `z → z² + c` on the complex plane. The key difference is how they are generated. The Mandelbrot set acts as a "map" or "catalogue" of all possible Julia sets. By clicking on a point `c` in the Mandelbrot set (shown in the picker window), you can generate and display the corresponding Julia set in the main window. You will discover that if you pick `c` from within the Mandelbrot set, the Julia set is a single, connected piece. If you pick `c` from outside, the Julia set shatters into a disconnected "dust."

Beginner's Guide to Julia and Mandelbrot Sets

Let's explore two of the most famous fractals in mathematics.

Step 1: The Magic Formula

Both fractals come from one incredibly simple formula: znext = zprev² + c. Here, `z` and `c` are "complex numbers," which can be thought of as points on a 2D plane.

Step 2: The Julia Set - A "Prisoner" vs. "Escapee" Map

To draw a Julia set, we first have to **pick a constant value for `c`**. This `c` value defines the "rule" for this specific Julia set.

Then, for every single point (`z₀`) on the main canvas, we apply the formula over and over again. We check if the point `z` flies off to infinity ("escapes") or if it stays trapped in a small region ("is a prisoner"). The Julia set is the boundary between these two regions. The color of a point indicates how quickly it escaped; black points are the prisoners.

The shape of the Julia set depends entirely on the `c` we chose.

Step 3: The Mandelbrot Set - A Map of Julia Sets

How do we know which `c` values to pick? That's where the Mandelbrot set comes in. The Mandelbrot set, shown in the picker window, is a kind of "catalogue" of all Julia sets.

A point `c` is part of the Mandelbrot set if its corresponding Julia set is **one single, connected piece**. If `c` is outside the Mandelbrot set, its Julia set is a **disconnected "dust"** of points (often called a "Fatou dust").

How to Use the Simulation

  1. Use the Picker Window: The right-hand window shows the Mandelbrot set. Click anywhere on this image.
  2. Choose a `c` value: Your click selects a complex number `c`. A crosshair will mark your selection.
  3. See the Julia Set: The main window on the left will then render the Julia set corresponding to your chosen `c`.
    • Try clicking **inside** the main black shape of the Mandelbrot set. You will see a connected Julia set.
    • Try clicking **outside** the main black shape. You will see a disconnected, dust-like Julia set.
