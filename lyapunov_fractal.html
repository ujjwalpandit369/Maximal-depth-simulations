Mapping the Edge of Chaos

You may have seen the bifurcation diagram of the logistic map, `x → r·x·(1-x)`. A Lyapunov Fractal is a different, 2D view into its behavior. Instead of a single growth parameter `r`, we use a sequence of two parameters, `A` and `B`, to control the map's iteration.

Step 1: The Parameter Space

The image is a map of a "parameter space."

  • The horizontal axis represents the value of parameter `A`, from 2 to 4.
  • The vertical axis represents the value of parameter `B`, from 2 to 4.
Each pixel on the image corresponds to a specific pair of `(A, B)` values.

Step 2: The Sequence and the Exponent

We iterate the logistic map, but at each step, we cycle through the `r` parameter according to the user-defined sequence. For the default sequence "AB", the map iterates as:
`x₁ = A·x₀(1-x₀)`
`x₂ = B·x₁(1-x₁)`
`x₃ = A·x₂(1-x₂)`
...and so on. For each `(A, B)` pair, we calculate the Lyapunov Exponent (λ). This number measures the rate of separation of infinitesimally close trajectories—it's a precise measure of how chaotic the system is.

Step 3: From Exponent to Color

The color of each pixel is determined by the calculated Lyapunov exponent:

  • ■ Blue/Teal regions (λ < 0): These are regions of order. For these `(A, B)` values, the system converges to a stable, periodic orbit.
  • ■ Gold/Yellow regions (λ > 0): These are regions of chaos. For these `(A, B)` values, the system is unpredictable and exhibits sensitive dependence on initial conditions.
The intricate, feathery boundary between these two regimes is the Lyapunov fractal. It has an incredibly complex and beautiful structure. Try changing the sequence to "AABB" or "BBA" and see how the map of chaos changes. Use your mouse wheel to zoom in and see the infinite detail.
