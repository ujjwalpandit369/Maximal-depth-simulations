Configuration Space of Knots

An interactive simulation of a physical rope that can be tied into different knots.

Current Crossings: 0

What is This?

This is a simulation of a flexible, self-avoiding rope whose ends are fixed. You can grab any point on the rope and drag it around. The number displayed above the canvas is the "crossing number"—a simple count of how many times the rope crosses over itself in this 2D view. This number is a simplified stand-in for a true mathematical knot invariant.

The Configuration Space of Knots

In mathematics, two knots are considered the same if you can wiggle, stretch, and bend one to look like the other *without ever passing the rope through itself*. This continuous deformation is called an "ambient isotopy." A true knot invariant is a quantity (often a number or a polynomial) that remains exactly the same during this wiggling. The only way to change a knot invariant is to fundamentally change the knot, for example by cutting it or passing it through itself.

This means that all possible configurations of a rope that form a trefoil knot live in one "region" of the total space of all possible rope shapes. All unknots live in a completely separate, disconnected region. You cannot get from one region to another by continuous deformation. This simulation demonstrates this concept:

  1. Start with the "Unknot." Drag it around. The crossing number may change as you wiggle it, but you can always get it back to 0 crossings without passing the rope through itself.
  2. Reset to the "Trefoil Knot" (a simple overhand knot). It has 3 crossings. No matter how much you wiggle and pull the rope, you will never be able to reduce the number of crossings to 0. The configuration is "stuck" in the trefoil knot region of configuration space.
  3. Uncheck the "Self-Avoidance" box. This turns off the physics that prevents the rope from passing through itself. Now you can drag one part of the rope through another, fundamentally changing the knot type. You will see the crossing number jump, and you can now transform the trefoil knot into an unknot.

A Note on the "Invariant"

Calculating a true knot invariant like the Jones or Alexander polynomial is extremely complex. This simulation uses the simple crossing number as an educational tool. Unlike a true invariant, the crossing number of a specific 2D projection *can* change during wiggling. However, the *minimum possible* crossing number for all possible wiggles *is* a true invariant. The key takeaway is that for a non-trivial knot like the trefoil, this minimum number is greater than zero.
