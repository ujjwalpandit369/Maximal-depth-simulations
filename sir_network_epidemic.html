Epidemic Spreading on a Network (SIR Model)

How social structure shapes the destiny of a disease.

One-Paragraph Overview

How a disease spreads through a population depends critically on "who knows whom"—the underlying structure of the social network. This simulation explores this idea using the classic Susceptible, Infected, Recovered (SIR) model of an epidemic. You can unleash a virus into three different types of networks: a highly ordered "Regular" network, a completely "Random" one, and a realistic "Scale-Free" network that contains highly connected "hubs." By watching the disease spread and observing the resulting epidemic curve, you can see firsthand how network structure is just as important as the disease's infectiousness, and why hubs in a scale-free network can act as super-spreaders that lead to explosive, widespread outbreaks.

Beginner's Guide — How a Sickness Spreads

Step 1: The S-I-R Model

This simulation uses a famous model in epidemiology. Every person (a node in the network) can be in one of three states:

  • Susceptible (S): Healthy, but can get sick. Initially, almost everyone is in this state.
  • Infected (I): Sick and contagious. They can pass the disease to their susceptible neighbors.
  • Recovered (R): No longer sick, no longer contagious, and now immune.

The disease spreads when an Infected node is connected to a Susceptible node. The recovery process is a random chance for any Infected person to get better at each time step.

Step 2: The Importance of Network Structure

The key idea here is that not all societies are structured the same. Use the "Network Topology" dropdown to explore three different types:

  • Regular Network: A highly ordered world where everyone has the same number of local neighbors. Think of people sitting in a grid. An infection spreads slowly and predictably, like a wave moving through the network.
  • Random Network: Connections are wired randomly. This creates "shortcuts" in the network, allowing the disease to jump to distant parts of the population much more quickly than in a regular network.
  • Scale-Free Network: This is the most realistic model for many real-world social networks. Most people have only a few connections, but a handful of "hubs" are extremely well-connected. Think of celebrities, major airports, or popular websites.

Step 3: Hubs as Super-Spreaders

Select the "Scale-Free" network and reset the simulation. You will see a few nodes that have many more connections than others. These are the hubs. Now, try to start an infection by clicking on a regular, low-connected node. The epidemic might be small and die out.

Reset again, but this time, start the infection by clicking on one of the major hubs. The result is dramatically different. The hub instantly exposes the disease to a huge fraction of the network, causing an explosive, widespread epidemic. This demonstrates why scale-free networks are so fragile and why identifying and protecting hubs is a critical strategy in public health.

Step 4: The Epidemic Curve

The bottom plot shows the number of people in each state over time. The red curve for "Infected" is the famous "epidemic curve." A key goal of public health is to "flatten the curve"—to slow the spread so that the peak number of infected people at any one time is lower, preventing hospitals from being overwhelmed. Try adjusting the Infection Probability slider to see how it affects the shape and height of this curve.

Core Theory — The Mathematics of Epidemics and Networks

1. The Agent-Based SIR Model

This simulation is an "agent-based" model. At each time step, we iterate through the rules for each agent (node):

  1. For each Infected node:
    • It has a chance `γ` (gamma) to recover, changing its state to Recovered.
    • For each of its neighbors that is Susceptible, it has a chance `β` (beta) to pass on the infection, changing the neighbor's state to Infected.

This process is repeated until there are no more Infected nodes.

2. The Basic Reproduction Number (R₀)

In simple "well-mixed" models, the most important number is the Basic Reproduction Number, `R₀` (R-naught). It represents the average number of people an infected person will pass the disease to in a fully susceptible population. It's estimated by:

R₀ ≈ β / γ

If `R₀ > 1`, the epidemic will grow. If `R₀ < 1`, it will die out. While this is a simplification for network models (the average number of connections also matters), it's a very useful guide. A higher `β` or lower `γ` leads to a higher `R₀` and a more severe epidemic.

3. Network Generation Algorithms

  • Regular (Ring Lattice): Nodes are arranged in a circle, and each node is connected to its `k` nearest neighbors on each side.
  • Random (Erdős-Rényi): Start with `N` nodes. For every possible pair of nodes, create an edge between them with a fixed probability `p`.
  • Scale-Free (Barabási-Albert): This uses "preferential attachment." Start with a small, connected network. Then, add new nodes one at a time. Each new node creates a fixed number of edges to existing nodes. The probability of connecting to an existing node is proportional to the number of connections that node already has. This "rich get richer" mechanism naturally creates the hubs.
