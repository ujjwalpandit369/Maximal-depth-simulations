Overview

Arnold's Cat Map is a famous example of a chaotic map on the surface of a torus (a donut shape, which we represent as a square with its edges "glued" together). The map takes every point in an image and moves it to a new location. When applied repeatedly, it demonstrates two key features of chaos: first, it acts as a perfect "mixer," rapidly scrambling the image into what looks like random noise. Second, because it is a deterministic process on a finite grid of pixels, it exhibits Poincaré recurrence: after a specific number of steps, the original image will magically reappear, perfectly intact. This simulation lets you apply the map step-by-step or automatically to see both the chaotic mixing and the surprising recurrence.

Beginner's Guide to a Chaotic Cat

Step 1: The Torus (A Square with Wrapped Edges)

The canvas shows an image on a square. This square represents a torus (the surface of a donut). Imagine gluing the left edge of the square to the right edge, and the top edge to the bottom edge. This means that if a point moves off the right side, it instantly reappears on the left side, and similarly for the top and bottom. This "wrapping" is crucial to the map's behavior.

Step 2: The Map - A Simple Transformation

The Cat Map is a very simple linear transformation applied to the coordinates of each pixel. For a pixel at `(x, y)`, its new position `(x', y')` is given by:

x' = (2x + y) mod N
y' = (x + y) mod N

Where `N` is the width of the image. The "mod N" part is what handles the wrapping around the edges of the torus.

Step 3: Chaotic Mixing

This simple rule has a profound effect. It strongly stretches and squeezes the image at every point. When you click the "Apply Map" button, you will see the image get sheared and distorted. After just a few clicks, the original image is completely unrecognizable, scrambled into apparent randomness. This is a hallmark of chaotic mixing.

Step 4: Poincaré Recurrence

Even though the image looks random, it is not. The map is just a permutation, shuffling the pixels around. Since there are a finite number of pixels, this shuffling must eventually repeat. If you let the simulation run using the "Auto-Play" button, you will see a surprising result: after a certain number of steps (the "Poincaré recurrence time"), the scrambling will reverse itself, and the original image will suddenly reappear, perfectly restored! This recurrence is a deep and fundamental property of deterministic systems.
