The Duffing Oscillator

A simulation of a driven, damped oscillator with a non-linear restoring force.

Est. runtime: Continuous | Recommended device: Desktop | Approx. size: 25 KB

Overview

The Duffing oscillator is a textbook example of how simple systems can exhibit profoundly complex behavior. It describes a "spring" that doesn't follow Hooke's Law perfectly, combined with friction (damping) and a periodic push (a driving force). While this sounds simple, the system is non-linear, and its behavior is incredibly rich. This simulation plots the system's trajectory in phase space (velocity vs. position). By adjusting the parameters, you can see the system's final state—its "attractor"—change from simple periodic motion into a complex, fractal strange attractor, the hallmark of chaos.

Beginner's Guide to a Chaotic Oscillator

Step 1: The Phase Space Plot

The canvas shows the "phase space" of the oscillator. The horizontal axis is the oscillator's position (x), and the vertical axis is its velocity (v). The complete state of the oscillator at any moment is just a single point on this graph. As the oscillator moves, this point traces a path called a trajectory.

Step 2: The Attractor

After a short initial period, the trajectory will settle onto a stable, repeating pattern. This pattern is called the system's attractor. The shape of the attractor tells you everything about the long-term behavior of the system.

Step 3: The Route to Chaos

The key to this simulation is using the sliders to change the system's parameters and observing how the attractor changes. You can use the presets to see classic examples:

  • Periodic Motion: For some parameters, the oscillator settles into a simple, repeating rhythm. The attractor is a single closed loop, called a "limit cycle."
  • Period-Doubling: As you change a parameter (like the driving force), you might see this loop split into a new loop that goes around twice before repeating. This is a "period-2" orbit. This splitting can happen again (period-4, period-8...), a process called a "period-doubling cascade," which is a classic route to chaos.
  • Chaos: For other parameter values, the trajectory never repeats itself, but it is still confined to a specific region. It will trace out an intricate, infinitely folded shape. This is a strange attractor. It has a fractal structure.

How to Use the Simulation

  1. Use the Presets: The easiest way to start is to click the preset buttons ("Periodic," "Period-2," "Chaotic") to see the different types of attractors.
  2. Adjust the Sliders: Change the "Driving Amplitude," "Driving Frequency," and "Damping" to explore the parameter space. The simulation will restart and trace the new attractor.
  3. Observe the Changes: Try to find the exact points where the behavior changes, for example, where a simple loop splits into a double loop.

Controls

Use the sliders to change the oscillator's parameters, or load a preset. The phase space plot will update automatically.
