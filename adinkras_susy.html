Drawing Supersymmetry

Supersymmetry (SUSY) is a proposed extension of the Standard Model of particle physics that relates two fundamental classes of particles: bosons (force-carriers, like photons) and fermions (matter particles, like electrons). It predicts that for every boson, there is a corresponding fermion partner, and vice-versa. The mathematics behind this is very complex. Adinkras are a recent invention that provides a simple, graphical way to represent these relationships.

How to Read an Adinkra

An Adinkra is a graph with a few simple rules:

  • Nodes: The circles represent the fields in a supersymmetry "multiplet."
    ○ White circles are bosons.
    ● Black circles are fermions.
  • Height: The vertical level of a node represents its mass dimension.
  • Edges: The lines represent the action of the supersymmetry operators, called `Q`. Each color corresponds to a different `Q` operator.
  • Line Style: A dashed line indicates a negative sign in the underlying algebraic relation, while a solid line indicates a positive sign.

Interacting with the Algebra

This simulation lets you perform the supersymmetry transformations visually.

  1. Select a field: Click on any node (a circle). It will be highlighted. The info panel will show which field you've selected.
  2. Select an operator: Now click on one of the colored edges connected to your selected node. This represents applying a `Q` operator.
  3. See the result: The node at the other end of the edge will be highlighted, and the info panel will show the full transformation, like `Q₂(φ) = ψ₁`.
Notice that a `Q` operator always connects a boson (white) to a fermion (black), visually enforcing the core principle of supersymmetry. You can also see that from any given node, each color of edge appears exactly once.

The Square of a Q

A fundamental rule of supersymmetry is that applying the same `Q` operator twice is related to a time derivative (a translation in time). `Q² = i∂/∂t`. While this simulation doesn't show time evolution, the graph structure reflects this: if you start at a node, follow a red line to a second node, and then follow the red line from that second node, you will always end up on a node directly above or below your starting point.
