Gravitational Lensing Simulator

An interactive tool to see how gravity bends light.

Plain-Language Overview

Gravity from a massive object curves spacetime, causing light to follow a bent path. This is gravitational lensing. If a massive "lens" (like a galaxy) lies between us and a distant "source" (like a quasar), we can see multiple, distorted images of the source. This simulation lets you set up your own cosmic alignment to see this phenomenon.

Beginner's Guide

1. The Setup

The main panel shows a top-down view: You are the Observer (eye) on the left. The Lens (orange) is a massive object. The Source (blue star) is a distant object. Lines represent light rays, which bend as they pass the lens.

2. What the Observer Sees

The right panel shows what you see. Because the light paths are bent, the source appears in a different position. These are lensed images.

3. Creating Cosmic Illusions

Try dragging the objects: Create multiple images by placing the source off-center. Create a perfect Einstein Ring by aligning the Observer, Lens, and Source. Create bright gravitational arcs with a near-perfect alignment.

Core Theory

General Relativity predicts that a light ray passing a mass M at a distance `b` will be deflected by an angle `α = 4GM / (bc²)`. This simulation uses a simplified version of this formula. The "Observer's View" is constructed by taking the angle of each incoming light ray that hits the observer and plotting a point at that angle on the viewscreen.
