Econophysics: Binomial Option Pricing

A simple model for valuing financial options.

Estimated Runtime: Interactive | Recommended Device: Desktop | Approx. HTML Size: 150 KB

Plain-Language Overview

A financial option gives you the right, but not the obligation, to buy or sell a stock at a set price in the future. Valuing such a contract today is a complex problem. The Binomial Option Pricing model is a foundational method in finance that simplifies this problem by assuming the stock price can only move to one of two possible values in each time step. This creates a branching "tree" of possible future prices. By knowing the option's value at the final branches (at expiration), we can work backwards through the tree to find its fair value today. This simulation visualizes the construction of this tree and the backward calculation.

Beginner's Guide — The Price Tree

Step 1: What is a Call Option?

This simulation prices a simple "European call option." This gives the holder the right to buy a stock at a pre-agreed **Strike Price (`K`)** on a specific **Expiration Date**. For example, an option to buy a stock at K=$100. If, on the expiration date, the stock price `S` is $110, the option is worth $10, because you can use it to buy a $110 stock for only $100. If the stock price is $90, the option is worthless, because you wouldn't use it to buy a $90 stock for $100.

Step 2: The Binomial Tree of Stock Prices

The model's core idea is to simplify the random movement of a stock price. It assumes that in any given time step, the price `S` can only do two things:

  • Move up by a factor `u` (e.g., multiply by 1.1).
  • Move down by a factor `d` (e.g., multiply by 0.9).
By repeating this over several time steps, we can build a branching tree of all possible future stock prices. The simulation shows this tree.

Step 3: Value at the End of the Tree

At the very last time step (the leaves of the tree), we know exactly what the option is worth. Its value is simply `max(0, S - K)`. The simulation calculates this value for each final node.

Step 4: Working Backwards with "Risk-Neutral" Probabilities

This is the clever part. How do we find the value of the option at a node *before* the end? We can't just average the two future possibilities, because an up-move might be more or less likely than a down-move. The model constructs a special "risk-neutral probability" `p` for an up-move. This isn't the real probability, but a mathematical tool that allows us to find the correct price.

The value of the option at any node is the **discounted expected value** of the two possible future nodes.
Value_today = (p * Value_up + (1-p) * Value_down) / (1 + r)
We take the weighted average of the two future values and then "discount" it back to the present using the risk-free interest rate `r`. The simulation applies this formula starting from the end of the tree and working backwards, node by node, until it reaches the start. The value at the very first node is the calculated fair price of the option today.

Model Parameters

Risk-Neutral Valuation

The entire model is built on the principle of "no-arbitrage," which means there should be no opportunity for risk-free profit. This principle is used to derive the risk-neutral probability `p`.

The up-move `u` and down-move `d` factors are often derived from the stock's volatility `σ` and the length of a time step `Δt` (here, we set `Δt=1` for simplicity).

u = exp(σ * sqrt(Δt)) and d = 1/u.

The risk-neutral probability `p` is then calculated such that the expected return of the stock in the risk-neutral world equals the risk-free rate `r`.

p = (exp(r*Δt) - d) / (u - d)

Backward Induction Formula

The value of a European call option `f` at any node `(i, j)` (where `i` is the time step and `j` is the number of up-moves) is the discounted expected value of the option in the next time step.

f_i,j = exp(-r*Δt) * [ p * f_{i+1, j+1} + (1-p) * f_{i+1, j} ]

This process starts at the final time step `N`, where the option values are known from the payoff function:

f_N,j = max(0, S_N,j - K)

Where `S_N,j` is the stock price at the final node, given by `S₀ * u^j * d^(N-j)`.
