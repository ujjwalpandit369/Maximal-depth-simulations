The Space of All Possible Shapes

Morphing between 2D shapes by traveling through "Shape Space".

Recommended device: Desktop/Mobile

Plain-Language Overview

"Shape Space" is a mathematical idea where every possible shape is a single point in a vast, high-dimensional space. A path between two points in this space represents a smooth transformation, or "morph," from the start shape to the end shape. This simulation lets you define two 2D shapes. When you press "Morph," it calculates a straight line path between them in shape space and visualizes the result as a fluid animation. This concept is powerful, with applications in computer animation, medical imaging, and biology.

Beginner's Guide

1. Representing a Shape as a Point

To a computer, a shape is just a list of numbers—the (x, y) coordinates of its corners (vertices). A square might be [(0,0), (1,0), (1,1), (0,1)]. This list of 8 numbers can be thought of as a single "point" in an 8-dimensional space. This is the core idea: any shape can be "plotted" as a point in a high-dimensional "shape space."

2. The Correspondence Problem

How do you morph a 4-vertex square into a 5-vertex pentagon? The simulation solves this by forcing both shapes to have the same number of vertices before morphing. If you draw a triangle (3 points) and a square (4 points), it automatically adds a new vertex to the triangle by splitting an edge. This is called resampling.

3. The Path Through Shape Space

Once two shapes, A and B, have corresponding vertices, the path between them is a straight line in shape space. The shape 30% of the way from A to B is found by moving each vertex of A 30% of the way towards the corresponding vertex of B. This is called Linear Interpolation ("Lerp").

Core Theory Notes

A 2D shape with n vertices can be represented as a single vector in a 2n-dimensional space: V = [x₁, y₁, x₂, y₂, ..., xₙ, yₙ]. This vector is a point in the shape space ℝ2n. The morphing process uses linear interpolation: Sᵢ(t) = (1 - t) * Aᵢ + t * Bᵢ, where `t` goes from 0 to 1.
