Guide: A Grammar for Growth

Lindenmayer systems, or L-systems, are a type of formal grammar—a set of rules and symbols used to generate complex strings. They were developed to model the growth of plants and have since become a popular way to generate beautiful fractals. The process has two stages:

  1. String Rewriting: The system starts with a simple string called the axiom. It then repeatedly iterates through the string, replacing characters according to a set of production rules. This process can quickly generate an immensely long and complex string from simple beginnings.
  2. Turtle Graphics: The final string is interpreted as a set of drawing commands for a "turtle." The turtle has a position and an angle, and it follows the commands in the string to draw the fractal.
    • F or G: Move forward by a set length, drawing a line.
    • +: Turn right by the specified angle.
    • -: Turn left by the specified angle.
    • [: Push the current turtle state (position and angle) onto a stack. This is like saving your place to start a new branch.
    • ]: Pop a state from the stack and return to it. This is like finishing a branch and returning to the main stem.
